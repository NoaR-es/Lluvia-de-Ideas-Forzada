### 📌 Descripción General

**Lluvia de Ideas Forzada** es una suite de aceleración cognitiva y gestión estructurada de ideas impulsada por modelos de lenguaje de última generación. Diseñada tanto para el ecosistema móvil (Android) como para la web, permite a creadores, investigadores, ingenieros y equipos multidisciplinares desbloquear bloqueos creativos mediante técnicas de pensamiento forzado (SCAMPER, Inversión de Supuestos, Analogías Cruzadas) y conectar su propia documentación mediante **RAG local (Retrieval-Augmented Generation)**.

#### 🌟 Pilares Fundamentales

1. **Madurez Botánica de Ideas:** Cada idea se cultiva como un organismo vivo clasificado en 5 estados evolutivos:
   - 🌱 **Semilla:** Intuición inicial o apunte en bruto.
   - 🌿 **Brote:** Idea estructurada con hipótesis preliminar.
   - 🪴 **Tallo:** Concepto en fase de desarrollo con documentación y viabilidad.
   - 🌸 **Flor:** Propuesta validada, contrastada y lista para prototipar.
   - 🍎 **Fruto:** Proyecto concluido, ejecutable y en fase de producción.

2. **Privacidad Radical y RAG Local:**
   - Modo 100% On-Device / Local para procesamiento offline seguro.
   - Modo Híbrido Nube mediante modelo **BYOK (Bring Your Own Key)** para Gemini y otros LLMs, sin intermediarios ni almacenamiento de claves en servidores de terceros.
   - Vectorización de documentos locales (PDF, Markdown, TXT) sin fugas de información.

3. **Colaboración Experimental P2P / Mesh:**
   - Intercambio directo entre dispositivos en red local sin dependencia de servidores centrales ni almacenamiento en la nube ajena.

4. **Hub de Tutoriales Interactivo y Responsive:**
   - Flujo formativo guiado paso a paso con deep linking (`#guia=`), control táctil, barra de progreso y gráficos vectoriales SVG explicativos.

### 📌 Overview

**Forced Brainstorming (Lluvia de Ideas Forzada)** is a cognitive acceleration and structured idea management suite powered by state-of-the-art language models. Designed for both the mobile (Android) and web ecosystems, it enables creators, researchers, engineers, and cross-functional teams to overcome creative blocks through forced thinking methodologies (SCAMPER, Assumption Reversal, Cross-Domain Analogies) and connect their own knowledge base via **local RAG (Retrieval-Augmented Generation)**.

#### 🌟 Core Pillars

1. **Botanical Idea Maturity:** Every concept is cultivated as a living organism categorized across 5 evolutionary stages:
   - 🌱 **Seed:** Initial gut feeling or raw flash of inspiration.
   - 🌿 **Sprout:** Structured concept backed by a preliminary hypothesis.
   - 🪴 **Stem:** Idea under active development with documentation and feasibility research.
   - 🌸 **Flower:** Validated, battle-tested proposal ready for rapid prototyping.
   - 🍎 **Fruit:** Concluded, production-ready, fully executable project.

2. **Radical Privacy & Local RAG:**
   - 100% On-Device / Local mode for secure offline execution.
   - Hybrid Cloud mode utilizing the **BYOK (Bring Your Own Key)** architecture for Gemini and other frontier models, without middleman proxies or external key storage.
   - Local document vectorization (PDF, Markdown, TXT) preventing data leaks.

3. **Experimental P2P / Mesh Collaboration:**
   - Direct local-network synchronization between devices with zero central server dependencies or external cloud custody.

4. **Interactive & Responsive Tutorial Hub:**
   - Step-by-step guided learning path equipped with deep-linking (`#guia=`), touch navigation controls, visual progress tracking, and explanatory SVG vector illustrations.
